# GIS-Based Spatial Analysis of Kathmandu District

## Overview

This project applies Geographic Information System (GIS) concepts and spatial analysis techniques to study geographic and population-related patterns in **Kathmandu District, Bagmati Province, Nepal**.

The project was developed using **ArcGIS** and focuses on spatial data management, georeferencing, data integration, spatial analysis, and thematic mapping.

## Objectives

- Create and organize a GIS workspace using a file geodatabase.
- Process administrative boundary data for Kathmandu District.
- Integrate municipality-level population data from **2011 and 2021** with spatial datasets.
- Georeference a topographic map using ArcGIS.
- Process and visualize geographic datasets such as roads, land use, and water bodies.
- Perform spatial analysis and verify spatial accuracy.
- Produce thematic maps showing population density and population change.

## Study Area

**Kathmandu District, Bagmati Province, Nepal**

The project focuses on the municipalities within Kathmandu District and examines their geographic characteristics and population changes between 2011 and 2021.

## Data Sources

The project used publicly available geographic and demographic datasets from:

- **National Geoportal Nepal** — administrative boundary data
- **City Population** — municipality-level population data for 2011 and 2021
- **Nepal Topographic Map Archive** — topographic map data
- **Geofabrik / OpenStreetMap** — geographic datasets such as roads and other features

## Project Workflow

### 1. GIS Workspace and Geodatabase Creation

A GIS workspace was created in ArcGIS using a **file geodatabase** to organize and manage the spatial datasets used throughout the project.

The geodatabase provided a structured environment for storing and processing the project's geographic layers.

### 2. Administrative Boundary Processing

Administrative boundary data was processed to extract and prepare the relevant **Kathmandu District and municipality boundaries**.

These boundaries were used as the spatial framework for integrating demographic data and performing subsequent analysis.

### 3. Population Data Integration

Municipality-level population data for **2011 and 2021** was collected and integrated with the corresponding spatial boundary layers.

This allowed population information to be represented geographically and enabled comparison of population distribution and changes between the two years.

### 4. Topographic Map Georeferencing

A topographic map sheet was georeferenced using ArcGIS.

The georeferencing process aligned the scanned map with its correct geographic location and coordinate system, allowing it to be used together with other spatial datasets.

### 5. Spatial Data Processing

Several geographic datasets were processed and integrated into the GIS workspace, including:

- Administrative boundaries
- Roads
- Land-use data
- Water bodies
- Population data
- Topographic map data

The datasets were prepared and organized so that they could be visualized and analyzed together.

### 6. Spatial Analysis

Spatial analysis techniques were applied to examine geographic and demographic patterns within Kathmandu District.

The analysis included the preparation of:

- Population-density maps
- Population-change maps
- General geographic feature maps

Spatial accuracy was also evaluated by comparing processed datasets with available topographic and administrative reference data.
